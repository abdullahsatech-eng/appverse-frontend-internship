## Purpose
A production-minded vanilla HTML/CSS demonstration for the CSS Architecture assignment.

## Architecture
1. tokens.css — centralized visual design tokens
2. base.css — reset, layout, responsive rules and component structure
3. utilities.css — single-purpose reusable utility classes
4. components.css — reusable UI primitives such as buttons and pills

## Concepts demonstrated
- BEM: Block, Element and Modifier naming
- Utility-first principles
- Design tokens with CSS custom properties
- Low-specificity and maintainable selectors
- Responsive design
- Component boundaries
- Accessible semantic HTML

## Example BEM naming

.product-card__media
.product-card__title
.product-card--featured
